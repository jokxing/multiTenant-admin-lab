# MultiTenant Admin Lab

一个脱敏的多租户后台能力演示项目。项目从真实管理后台中提炼通用前端能力，使用本地 Mock 数据运行，不包含公司名称、业务接口、客户数据或生产配置。

基于 Vue 3、TypeScript、Vite、Naive UI、Pinia 和 SoybeanAdmin 构建。

## 核心能力

### 页面配置与发布

- JSON Schema 与可视化设计双向同步
- 动态表格列、表单字段和操作按钮配置
- `form`、`confirm`、`slot` 三类操作执行器
- 操作表单、条件显隐、校验规则和动态预览
- 草稿差异、发布校验、版本记录与回滚
- 搜索、筛选、虚拟滚动和个人列偏好

### 多租户 RBAC

- 平台超管、租户管理员、审核专员三类角色
- 页面 Schema 自动注册按钮权限点
- 权限树编译为 `route_keys`
- 页面级与按钮级权限过滤
- 待发布变更、策略发布和审计记录
- 配置视图与角色视图对照验证

### 实时消息可靠性

- 连接状态与指数退避重连
- 消息唯一 ID 和幂等去重
- 突发消息顺序消费队列
- 多业务待办计数聚合
- 分类声音偏好和音频串行队列
- 事件流水与消费指标

## 推荐演示路径

1. 在“页面配置器”新增表格列或操作按钮。
2. 为 `form` 类型按钮设计操作表单。
3. 查看草稿差异并发布新版本。
4. 切换角色视图，观察未授权按钮被隐藏。
5. 前往“角色权限配置”发布按钮权限。
6. 返回角色视图或权限实验台验证结果。
7. 在实时消息中心演示重复消息和断线重连。

## 权限与配置链路

```text
页面 Schema 定义权限点
        ↓
权限中心分配角色权限
        ↓
发布 route_keys
        ↓
运行时过滤页面与按钮
```

## 本地运行

```bash
pnpm install
pnpm dev
```

类型检查与生产构建：

```bash
pnpm typecheck
pnpm build
```

## 数据与隐私

- 所有租户、用户、金额和申请数据均为模拟数据。
- 不包含真实公司名称、域名、接口地址、密钥和数据库信息。
- 配置版本、表格偏好和声音设置仅保存在浏览器本地。
- 首页提供“重置 Demo”，可恢复初始演示状态。
