# MultiTenant Admin Lab

面向前端岗位的后台工程作品，从实际 SaaS 后台工作中提炼配置驱动页面、公共组件、权限协作及移动端编排经验。当前使用模拟业务数据展示，不提供生产业务后端。

基于 Vue 3、TypeScript、Vite、Naive UI、Pinia 和 SoybeanAdmin 构建。

重点案例是配置生成列表中的复杂排序和多语言素材组表单：展示如何把通用结构交给配置，把复杂交互封装为组件，并通过统一动作入口处理保存、失败反馈及状态恢复。

## 核心能力

### 页面配置与发布

- JSON Schema 与可视化设计双向同步
- 动态表格列、表单字段和操作按钮配置
- `form`、`confirm`、`slot` 三类操作执行器
- 操作表单、条件显隐、校验规则和动态预览
- 草稿差异、发布校验、版本记录与回滚
- 搜索、筛选、虚拟滚动和个人列偏好
- 配置驱动列表排序（内容推荐列表：拖拽 / 置顶 / 上移 / 下移）
- 配置驱动复杂表单（多语言素材组：简/繁/英 + 本地素材样例）

### 角色权限演示

- 平台超管、租户管理员、审核专员三类角色
- 页面 Schema 自动注册按钮权限点
- 权限树编译为 `route_keys`
- 页面级与按钮级权限过滤
- 待发布变更、策略发布和内存审计记录
- 配置视图与角色视图对照验证

### 实时待办与消息处理演示

- 连接状态恢复模拟与退避延迟公式
- 消息唯一 ID 和当前页面内去重
- 突发消息顺序消费队列
- 多业务待办计数聚合
- 分类声音偏好和音频串行队列
- 事件流水与消费指标

## 推荐演示路径

1. 在“页面配置器”新增表格列或操作按钮。
2. 为 `form` 类型按钮设计操作表单。
3. 查看草稿差异并发布新版本。
4. 切换角色视图，观察未授权按钮被隐藏。
5. 前往“角色权限配置”发布按钮权限。
6. 返回角色视图或权限实验台验证结果。
7. 在实时消息中心演示重复消息和断线重连。
8. 新建或打开“内容推荐列表”，发布后在运行时演示排序列（含保存失败回滚）。
9. 新建或打开“多语言素材组表单”，发布后演示语言切换保留输入、校验定位与保存失败保留。

类型检查、生产构建与业务验证：

```bash
pnpm typecheck
pnpm build
pnpm test:demo
```

## 权限与配置链路

```text
页面 Schema 定义权限点
        ↓
权限中心分配角色权限
        ↓
发布 route_keys
        ↓
运行时过滤页面与按钮
```

## 本地运行

要求 Node.js ≥ 20.19.0、pnpm ≥ 10.5.0。访问终端输出的开发地址，端口占用时 Vite 可能选择其他端口。

```bash
pnpm install
pnpm dev
```

类型检查与生产构建：

```bash
pnpm typecheck
pnpm build
```

## 原项目与当前作品

本人从原项目开始主导 SaaS 后台前端，负责技术选型、前端结构、需求拆解、接口协商、复杂功能及公共组件封装，并负责后台代码评审。另一名前端主要负责移动端；后来新增前端承担较简单的后台页面配置、菜单及接口工作。

原后台已有配置驱动列表与表单、复杂组件、后端菜单权限和 WebSocket。当前作品提炼这些工程思想，不完整复现原配置引擎；配置发布与版本回滚属于本次 AI 辅助提炼新增能力。框架基础、原项目经历和展示阶段新增实现分别说明，详见[个人贡献与能力来源](docs/project-guide.md#项目背景与个人贡献)。

## 数据与实现边界

- 所有租户、用户、金额和申请数据均为模拟数据。
- 推荐演示账号可本地登录；请求层仍保留上游公共 Mock 服务配置及非演示登录、Token 刷新等请求分支，不能将整个工程描述为完全离线应用。
- 配置版本、排序、素材组草稿和部分偏好保存在浏览器；权限策略与演示审计使用内存状态，没有服务端持久化审计或租户数据隔离。
- 前端过滤按钮不等于接口授权；配置器的预览角色与登录身份分别控制。
- 实时待办页不连接真实 WebSocket；移动端客服 HTTP/SSE Mock 属于另一条链路。
- 列表排序展示完整列表内的调整，不支持跨页与子列表排序；素材为本地 SVG 样例，不提供上传服务。
- 首页提供“重置 Demo”，可恢复初始演示状态。

2026-10-09 已通过示例测试、类型检查、生产构建及两条代表链路的本地 Edge 浏览器回归。完整范围见[验证记录](docs/implementation-review.md#验证命令及结果)，不代表全部模块、设备和浏览器均已验收。
